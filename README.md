# For Ji ♡

Website proposal romantic (tema black) dari Daffa untuk Ji (Jihan).

## Jalankan

```bash
npm install
npm run dev
```

Build produksi: `npm run build` (hasil di folder `dist/`).

## Musik (opsional)

Taruh file lagu di `public/music/background.mp3`. Tombol "Music" di pojok kanan atas akan memutarnya.

## Alur

Ji harus klik **YES** di setiap pop-up untuk lanjut. Kalau klik **NO**, muncul pop-up balasan lalu kembali ke pop-up yang sama.
Di akhir ada pertanyaan inti, lalu layar sukses kalau dia jawab YES.

## Ubah teks

Semua teks cerita ada di array `steps` di `src/App.jsx`.
